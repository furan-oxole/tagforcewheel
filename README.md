# Tag Force Wheel

**Tag Force Wheel** permette di estrarre mazzi casuali dai giochi *Yu-Gi-Oh! Tag Force* oppure di creare una ruota personalizzata.

Con **Ruota Tag Force** puoi scegliere un gioco, estrarre un mazzo, visualizzarne le carte e scaricare la ricetta. Puoi anche consultare l'**Elenco Mazzi** ed escludere i mazzi che non vuoi estrarre.

Con **Ruota personalizzata** puoi inserire nomi o frasi e girare la ruota per estrarne uno a caso.
